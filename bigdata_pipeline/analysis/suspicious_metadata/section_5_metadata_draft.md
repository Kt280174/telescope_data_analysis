# Дополнение к разделу 5: метаданные каналов

Для 33,360 ранее отобранных пар использованы исходные метаданные каналов и почасовые профили активности. Из 8,114 каналов-кандидатов 8,094 сопоставлены с метаданными; 8,094 имеют пригодный профиль 24 часов. Объекты User/ботов исключены из сопоставления с каналами по числовому ID.

Сходство почасовых профилей вычислено для 33,291 пар; медианная косинусная близость: 0.946. Профили нормированы на сумму входных 24 значений. Для сравнения сопоставлено 8,050 каналов вне списка кандидатов по наблюдаемому языку и квантилю объёма входных почасовых значений, без повторного использования каналов. Отсутствующие соответствия и флаги отражены в таблицах; контрольные каналы не считаются заведомо нормальными.

Общая ссылка в описании найдена у 0 пар, общий Telegram-target — у 0. Это ссылки в профилях, не сущности сообщений. Общие контакты могут указывать на редакционную или организационную связь, но сами по себе не доказывают её и не устанавливают фишинг.

Сопоставление scam/fake/restricted/verified представлено с числом пар каналов, для которых оба значения известны. Эти признаки не определяют долю ложных срабатываний детектора. Почасовое сходство, возраст и ссылки используются как дополнительный контекст к временной синхронности, а не как самостоятельное доказательство ботов, спама или злонамеренной координации. generic Channel.date не интерпретируется автоматически как дата создания.
